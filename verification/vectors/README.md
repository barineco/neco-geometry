# 幾何演算の検証ベクター

検証ベクターは、検査器が正しい観測を受理し、改変した観測と形式に反する入力を拒否することを、手元で確かめるための入力です。演算族、型付き失敗、正規の JSON の定義は [`protocol/README.md`](../protocol/README.md) にあります。`generated/` を除く三つのディレクトリでは、検査器が返すべき判定がディレクトリごとに決まっています。

- `known/`: 初版の演算族の成功値と型付き失敗。検査器は全ての観測を `verified` と判定する
- `tampered/`: 正規の JSON の規約を保ったまま、観測値の一箇所を書き換えた観測バッチ。検査器は `refuted` と判定する
- `invalid/`: 形式または正規の JSON の規約に反する入力。検査器はバッチ全体を不正と判定する。ただし、初版に無い演算族を持つ観測では、その観測だけを不正と判定する
- `generated/`: テストで作った生成要求と、生成器がそれに対して作った観測バッチ

複製のルートで、`verification/lean` ディレクトリに移動し、構築した検査器で次のコマンドを実行すると、`generated/` を除く三つのディレクトリのベクターを検査し、期待と異なる判定があればエラーで終了します。

```sh
cd verification/lean
.lake/build/bin/neco-geometry-checker all
```

`known/` と `tampered/` の検証ベクターは、形式識別子と観測一覧の二つの項目を持つ正規の JSON の文書です。

- 形式識別子: `schema`
- 観測一覧: `cases`

観測一覧の各観測は、観測識別子、演算族、入力、観測値の四項目だけを持ちます。

- 観測識別子: `caseId`
- 演算族: `operation`
- 入力: `input`
- 観測値: `observation`

`known/families.json` は、6 種類の演算族それぞれについて、成功値を持つ観測と型付き失敗を持つ観測を収めた観測バッチです。

`generated/` の二つのファイルは、生成器の入力と出力の例です。生成要求のファイルは 1,008 件の生成要求を、観測バッチのファイルはそれに対応する 1,008 件の観測を含みます。

- 生成要求: `generated/smoke-request.json`
- 観測バッチ: `generated/smoke-batch.json`

二つのファイルは、`rust` ディレクトリで `cargo test --locked` を実行した時に、生成器のテストが書き出したものです。
