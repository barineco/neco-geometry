# neco-geometry

[English](README.md)

`neco-geometry` は、実代数的数を座標とする曲線や曲面について、評価と演算を行うクレートです。評価の結果は、厳密な値または包含区間 ( 真の値を必ず含む区間 ) です。

## 主要機能

**形状の宣言と評価**

曲線と曲面の宣言を、厳密な値として、または包含区間として評価します。

- 曲線: 有理チャート ( chart、パラメータの有理式で座標を与える写像 )
- 媒介変数曲面: 二つのパラメータの有理式で座標を与える曲面
- 陰関数曲面: 疎な多変数多項式

包含区間には来歴を付けます。来歴は、所有者の識別子、評価の要求、計算した実装の版と公開 API の識別子からなります。
評価の要求は、消費点の識別子、対象の式、判定の指定、精度を含みます。消費点は、評価の結果を受け取る利用箇所です。判定の指定は、消費点が求める厳密な判定の種類 ( 零、等値、符号、縮退 ) と、対象の式のうち、その判定で調べる式 ( 等値の判定では二つの式 ) を表します。

**代数的領域の判定**

領域は、関数の符号条件と、それらを組み合わせた論理式で表します。指定した点が内部・境界・外部のどこに属するかを判定します。

**交差の厳密な構成**

2 つの形状と根を分離する設定 ( 二分法などの絞り込み方法、反復の上限、目標の区間幅 ) から、交差集合 ( 点、曲線、二つの形状が一致する部分など ) を構成します。
交差集合には、根の存在と一意性の根拠を付けて返します。

**境界の導出と次元ごとの分割**

呼び出し側は、代数的領域の符号条件ごとに境界の候補を与えます。候補は、多項式で表した曲線 ( 制限チャート ) 、その曲線の上で境界の点となりうるパラメータ値、境界の両側を調べるパラメータ値からなります。候補では、呼び出し側が境界の導出に与えた交差集合 ( 交差の構成の結果 ) の一つを、番号で指定することもできます。
このクレートは、各候補の曲線の上で符号条件の関数を評価して、代数的領域の境界を導出します。
導出した境界は、0 次元、1 次元、2 次元の部分に分けます。候補が交差集合を指定している場合、その候補から導いた部分は、交差集合が点であれば 0 次元、曲線であれば 1 次元です。
次元を確定できない部分には、理由を付けて返します。

**半直線との交差**

3 次元の半直線と、三角形または曲面との交差を、半直線のパラメータが正である範囲全体で評価します。

- 三角形
- 切り取り済みの媒介変数曲面 ( パラメータ領域を、外周と穴を表す多角形の切り取り輪郭で限った曲面 )
- 陰関数曲面

評価は、始点の接触と交点の列を常に返し、結果が確定した場合は交差の偶奇を、未確定の場合は未確定の理由を返します。

- 始点の接触: 半直線の始点が、対象の内部または境界の上にあるか
- 交差の偶奇: 交差の回数が偶数か奇数か
- 交点: 順序付きの交点の列
- 未確定の理由: 結果が未確定の場合に返す型付きの理由

**曲面パッチ**

曲面パッチを表す `ChartPatch` は、次の 2 種類です。

- 円板制約を任意で持つチャート
- 切り取り済みの宣言

円板制約の `DiskConstraint` は、二つのパラメータが閉じた単位円板に含まれるかを厳密に判定します。

**借用参照で読み取れる情報**

- チャート
- 定義域
- 円板制約
- 切り取り済みの宣言

この機能は、CAD や GPU のクレートに依存しません。

### 数値符号化

曲面パッチと seam ( 曲面のパラメータ点どうしの対応付け ) を有限の f32 データに変換し、丸め誤差の上界を別の値で返します。

**保持する情報**

- 多項式の指数
- 定義域の開閉
- 外周と穴の頂点列
- 円板制約
- 向き

**主な API**

- `encode_chart_patch`: パッチの数値データと丸め誤差上界を返す
- `encode_seam_association`: seam の両端を同じ方法で数値化する
- `EncodedSeamAssociation`: 元の順序で保持する両端の二変数と向き
- `EncodingPrecision`: 1–256 bit の包含区間の精度と、有限・非負の最大丸め誤差
- `EncodedSurfacePatch`: 通常または切り取り済みの数値パッチ
- `EncodedCoefficients`: x・y・z・分母の順の項列
- `EncodedDomain`: 二変数の上下端点と開閉
- `EncodedTrimRestriction`: 外周と穴の頂点列
- `EncodingBounds`: F32 形式と、全値の丸め誤差上界の最大値
- `EncodingFailure`: 入力位置を持つ、精度・表現範囲・下位演算の失敗

有理数・代数的数の包含区間の中点を f64 経由で f32 に変換します。
得られた f32 を厳密な二進有理数へ戻し、`RealAlgebraic` 型の値を符号化する場合は、その値が元の区間に含まれるとき、`RealAlgebraic` 型の元の値と厳密に比較します。
候補と元の値が厳密に等しい場合は、その値の誤差上界を 0 とします。
それ以外の場合は、区間の両端との差を厳密な二進有理数で求め、大きい方を誤差上界として f64 で上方に丸めます。
各値の誤差上界の最大値を `EncodingBounds` に一度だけ返します。

chart の識別子と利用側の形状要素 ( primitive ) の識別子の対応付けは、呼び出し側の責務です。

呼び出し側は丸め誤差を評価へ伝え、GPU の算術誤差と合成します。符号化は CPU 側で動作し、core と alloc で利用できます。

### GPU 交差評価

任意の `gpu` 機能を有効にすると、アフィン平面と、分母が `1 + u² + v²` の立体射影で表す球面を対象に、GPU 上で交差と接触を評価できます。
符号化したパッチと丸め誤差上界から GPU 向けの数値表現を構築し、数値評価・交差評価・利用側の entry point ( 利用側が用意する呼び出し口 ) を一つの WGSL プログラムへ合成して使います。

```text
GpuCrossingSurface::from_encoded: GPU 向けの数値表現を構築する API
GPU_CROSSING_WGSL: 交差と接触を評価する WGSL コード
NecoGpuSurface / neco_gpu_surface: 数値評価コードが定義する曲面の型と評価関数
entry point: 利用側が用意する呼び出し口
```

GPU の資源確保と実行も利用側が行います。用途に応じて次の WGSL 関数を選びます。

- `neco_gpu_surface_bounds`: パラメータ領域の長方形上の曲面を、符号化の誤差を含む三次元の範囲に包含する
- `neco_gpu_surface_ray_excluded`: 半直線の除外を確定したとき `true` を返す。閉じた端点との接触と、数値的に判定が未確定な場合は、接触の評価の候補として保持する

- `neco_gpu_surface_contact`: 近似的な点候補を求める。残差とパラメータ領域への包含を検査し、元の式と GPU の数値表現が一致して演算から判定できる二重根や trim の外周の辺を扱う。判定が不確かな結果は `Unknown` とする

  ```text
  Hit / Miss / Unknown / LowerEvaluationFailure
  ```

- `neco_gpu_contact_normal`: 同じ幾何の数値表現と接触の候補から、曲面の向きを保った近似単位法線を世界座標で返す。法線は Hit の候補でだけ得られる。

  ```text
  valid = 0: 非有限な値、退化した微分、Hit 以外の入力
  valid = 1: 上記以外の有効な場合
  ```

- `neco_gpu_contact_seam_classification`: 点候補を得たときに、独立した seam の近傍分類を読み取る。近傍内を表す `Contact` は、点候補と seam の端点との距離を誤差と比較して定める

  ```text
  Off / Contact / Unknown
  ```

- `neco_gpu_crossing`: 同じ点候補を使って交差全体を判定し、seam の近傍内にある場合と、その判定が不確かな場合に、全体を判定不能として返す

## 主な仕様と制約

制約は、演算の信頼性を保ち、計算資源の消費を抑えるために設けています。その値は実行環境によらず一定です。

| 操作 | 制約 | 制約に違反した時の挙動 |
|---|---|---|
| **交差の構成** | 根を分離する設定の反復の上限 ( パラメータ区間を二分する深さ ) 19 以下、二分で生じる部分区間 65,535 個以下 | `GeometryFailure` を返す |
| **境界の導出** | 境界の候補 64 件以下、交差集合 16 件以下、候補ごとのパラメータ値と、境界の両側を調べるパラメータ値はそれぞれ 4,096 件以下 | `GeometryFailure` を返す |
| **入力の検証** | 無効な区間、重複した項や係数が零の項を持つ多項式、不正な次元、領域を表す不正な論理式、不正な設定 ( 根を分離する設定など ) を拒否する | 構築時に拒否する、または型付きの `GeometryFailure` を返す |
| **曲面のチャートと切り取り** | 分母の多項式が 1 つ以上の項を持つこと。各切り取り輪郭は、パラメータ領域の中に 3 個以上の頂点を持つこと。自己交差する輪郭と、外周の輪郭と交わる穴の輪郭は拒否する | `GeometryFailure` を返す |
| **半直線との交差** | パラメータの範囲は正の値全体。呼び出し側が宣言した対象の数と交点の数の上限。退化した三角形 ( 三頂点が一直線上にあるもの、または非有限の頂点を持つもの ) と、不正な切り取り輪郭の拒否 | 型付きの失敗、または未確定の結果を返す |

## ランタイム構成

既定の構成では、標準ライブラリを使います。

```toml
[dependencies]
neco-geometry = "0.2"
```

既定の `std` 機能を無効にすると、動的メモリ確保だけを前提に動作するため、標準ライブラリの無い環境でも使えます。返す値の意味も失敗の意味も、既定の構成と同じです。

```toml
[dependencies]
neco-geometry = { version = "0.2", default-features = false }
```
