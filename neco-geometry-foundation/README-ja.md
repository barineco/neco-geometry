# neco-geometry-foundation

[English](README.md)

`neco-geometry-foundation` では、実代数的数を座標とする幾何の基礎型を定義し、それぞれの型の不変条件を厳密に検証します。方向、直交行列、単位四元数、チャートの宣言は、不変条件を満たす場合に限り構築できるため、構築した値は常にその型の不変条件を満たします。

## 主要機能

**厳密な幾何プリミティブ**

2 次元・3 次元の点とベクトルを、次元ごとの型として定義しています。座標は実代数的数で表し、$\sqrt{2}$ のような無理数の座標も近似を挟まずに保持します。

- 点: `Point2`, `Point3`
- ベクトル: `Vector2`, `Vector3`

**幾何変換と回転**

方向、直交行列、単位四元数、変換を表す型を定義しています。
変換は、直交行列と平行移動のベクトルを組にした値で、3 次元の変換は回転を表す単位四元数も持ちます。
直交行列と単位四元数の不変条件は、それぞれの型を構築する時に検証します。
3 次元の変換は、直交行列と単位四元数をそのまま公開フィールドに持ちます。両者が同じ回転を表すことは、変換を構築する側で確かめる必要があります。

**検証済みのチャートの宣言**

有理チャート ( chart ) は、一つのパラメータの有理式で 2 次元または 3 次元の座標を与える写像です。有理チャートの宣言は、チャートのパラメータの定義域を識別する文字列 ( `ChartDomainId` ) と、表示名とを別々の値として保持します。
2 つのチャートは、定義域の識別子が一致する場合に合成できます。表示名は表示にだけ使い、合成の可否は定義域の識別子だけで決まります。

## 不変条件と検証規則

不変条件は、値を構築する時と、チャートを合成する時に検証します。ノルムと内積は実代数的数で計算するため、表の「厳密に 1」「厳密に直交」の判定は、厳密な値どうしの比較で行います。

| 対象 | 不変条件 | 違反した時の挙動 |
|---|---|---|
| **方向** | 元のベクトルが零ベクトル以外であること | 構築時に拒否 ( `GeometryFailure` ) |
| **直交行列** | 各列のノルムが厳密に 1 で、異なる列どうしが厳密に直交すること | 構築時に拒否 ( `GeometryFailure` ) |
| **四元数** | ノルムが厳密に 1 であること ( $w^2 + x^2 + y^2 + z^2 = 1$ ) | 構築時に拒否 ( `GeometryFailure` ) |
| **チャートの宣言** | 定義域の識別子と表示名が 1 文字以上であること、分母が零以外であること | 構築時に拒否 ( `GeometryFailure` ) |
| **チャートの合成** | 2 つのチャートの定義域の識別子 ( `ChartDomainId` ) が一致すること | `GeometryFailure::ChartDomainMismatch` を返す |

## ランタイム構成

既定の構成では、標準ライブラリを使います。

```toml
[dependencies]
neco-geometry-foundation = "0.1"
```

既定の `std` 機能を無効にすると、動的メモリ確保だけを前提に動作するため、標準ライブラリの無い環境でも使えます。返す値の意味も失敗の意味も、既定の構成と同じです。

```toml
[dependencies]
neco-geometry-foundation = { version = "0.1", default-features = false }
```
